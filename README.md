# Cadastro de usuário em Flutter

Tela de cadastro com validação campo a campo, filtros numéricos para CPF e telefone, confirmação de senha e feedback por SnackBar.

## Preparar e executar

Com o Flutter SDK instalado, abra o terminal nesta pasta e rode:

```powershell
flutter create . --platforms=android,ios,web,windows
flutter pub get
flutter run
```

O comando `flutter create .` gera os arquivos de plataforma do projeto e preserva `lib/main.dart` e o `pubspec.yaml` existentes.
